An original image made to excite an AI judge: a luminous phoenix rising over a
bioluminescent ocean at dawn, embers trailing and aurora light rippling across
the sky. One clear focal subject, vivid colour, high contrast, and a sense of
wonder and scale — built to stand out in pairwise comparison.

This is an entry for the [make.fun](https://make.fun) bounty
[ai-excited-01](https://make.fun/bounty/ai-excited-01).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` into the output directory as `entry.png`, byte for
byte (verified with `sha256sum`). Requires Node 22 or later, standard
library only — no dependencies to install.
